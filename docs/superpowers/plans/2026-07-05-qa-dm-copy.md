# qa-service: Delegated 回答の DM 永続コピー — 実装プラン

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Delegated モードのエフェメラル回答(非永続・通知なし)を補い、質問者の Bot DM に「質問抜粋 + スレッド permalink + 回答全文」の永続コピーを best-effort で送る。

**Architecture:** `SlackClient` トレイトに `open_dm`(conversations.open)と `permalink`(chat.getPermalink)を追加し、新モジュール `answer/dm_copy.rs` が DM 本文整形(純粋関数)と送信オーケストレーションを担う。`pipeline.rs` の Delegated arm は `post_ephemeral` 成功後に 1 呼び出しするだけ。失敗はすべて warn ログで握り、回答フローは成功扱い。

**Tech Stack:** Rust / tokio / async-trait / reqwest(既存 `post_form` パターン)/ serde(config)

**スペック:** `docs/superpowers/specs/2026-07-05-qa-dm-copy-design.md`

## Global Constraints

- `#![forbid(unsafe_code)]` — 全クレート
- `Utc::now()` / `SystemTime::now()` を production コードで呼ばない(本機能は時刻を扱わないため Clock 注入も不要)
- clippy は CI 相当の `cargo clippy --workspace --all-targets --all-features --locked -- -D warnings` で確認
- DB 依存テストは `DATABASE_URL` 未設定時に silent skip する。フル検証は `just pgmq-up` + `DATABASE_URL` 設定 + `just db-migrate` 後に実行
- コミットは Conventional Commits(crate スコープ、跨るものは `workspace`)。**gpgsign 無効で実行**: `git -c commit.gpgsign=false commit ...`(1Password Touch が背景実行をブロックするため)
- 作業ブランチ: `feat/qa-dm-copy`(作成済み)

## 前提知識(このリポジトリ固有)

- `AnswerMode::Delegated` の回答は `crates/qa-service/src/answer/pipeline.rs` の step 4 で `chat.postEphemeral` により投稿される。スポーン失敗通知(step 1)は今回の DM 対象外

```rust
pub fn build_dm_text(question: &str, permalink: Option<&str>, answer: &str) -> String {
    // 改行・連続空白を単一スペースに潰してから chars ベースで切る
    // (バイト境界 slice は日本語質問で panic する)。
    let flat = question.split_whitespace().collect::<Vec<_>>().join(" ");
    let mut excerpt: String = flat.chars().take(QUESTION_EXCERPT_CHARS).collect();
    if flat.chars().count() > QUESTION_EXCERPT_CHARS {
        excerpt.push('…');
    }
    let mut out = format!("💬 *質問:* 「{excerpt}」\n");
    if let Some(link) = permalink {
        out.push_str(&format!("🔗 {link}\n"));
    }
    out.push('\n');
    out.push_str(answer);
    out
}

pub async fn send_dm_copy(
    slack: &dyn SlackClient,
    user: &str,
    channel: &str,
    thread_ts: &str,
    question: &str,
    answer: &str,
) -> Result<(), QaError> {
    // permalink は装飾 — 取れなくても DM 本体は送る。
    let permalink = match slack.permalink(channel, thread_ts).await {
        Ok(l) => Some(l),
        Err(e) => {
            tracing::warn!(error=%e, thread_ts, "permalink fetch failed; sending DM without link");
            None
        }
    };
    let dm_channel = slack.open_dm(user).await?;
    let text = build_dm_text(question, permalink.as_deref(), answer);
    slack.post_message(&dm_channel, None, &text).await?;
    Ok(())
}
```
