## About these pages

These pages are written for people using totsuka. They are generated from the repository's internal knowledge base under `ai-docs/`, with the design decisions, measurements, and issue history stripped out.

If you are working on totsuka itself — or you want to know *why* something is the way it is — read `ai-docs/` instead. Each page here names its source document at the bottom.
