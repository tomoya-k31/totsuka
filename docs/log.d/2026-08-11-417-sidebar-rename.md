* **Update**: dispatch が workspace の label を `{repo}: {タイトル}` に rename するようになった（#417 PR-3、[ADR-0039](/decisions/adr-0039-herdr-sidebar-identity.md) D4）。**`workspace.create` が書くのは今までどおり `totsuka {task.id}`** で、rename は**報告が両方成功したときだけ**。この順序のおかげで、herdr が途中で詰まっても「機械 label のまま」に留まり、**label と token の両方から identity が消える瞬間が無い**。同じ順序が `session/release` の「token を label より信用してよい」根拠にもなっている — token が無い container は rename もされていないので、label 経路が比較するマーカー形式のままである [agent-ide-herdr プラグイン](/components/agent-ide-herdr.md)
* **Creation**: [herdr サイドバー設定](/references/herdr-sidebar-config.md) と [herdr サイドバーに repo / タスクを出す](/operations/herdr-sidebar-setup.md)。**totsuka は `~/.config/herdr/config.toml` を一切書き換えない**（D6）ので、報告したトークンを画面に出すかどうかは運用者の設定であり、**スニペットを入れるまで行は増えない**。この「実装しても既定では見た目が変わらない」性質は、書いておかないと不具合に見える
