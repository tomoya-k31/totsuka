* **Update**: [ADR-0032](/decisions/adr-0032-herdr-protocol-17.md) D-7 と [agent-ide-herdr](/components/agent-ide-herdr.md) を拡張。herdr の起動過渡状態が 2 段あることが実機で判明した — `agent.start` の成功は `launch_pending: true` / `agent_status: unknown` を返すことがあり、その間 `agent.prompt` は `agent_not_ready` で拒否する（実測: start が t=1.0s、prompt が通ったのは t=5.0s）。応答は非決定的で同じ状況が `agent_pane_busy` にも `launch_pending` にもなるため、両方を同じ予算でリトライする。`agent_not_found` は除外（pane が死んだ形で、resume 付き dispatch では `SESSION_UNRESUMABLE` として上げる必要がある）。あわせて `agent_session`（`--resume` の識別子）が統合の明示インストール無しに報告されることを確認し、ADR の未解決項目を 1 つ閉じた。
