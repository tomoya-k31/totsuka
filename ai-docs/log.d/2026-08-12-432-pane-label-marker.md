* **Update**: dispatch が **pane にも機械マーカーを書く**ようになった（#432、[ADR-0039](/decisions/adr-0039-herdr-sidebar-identity.md) D7）。`herdr server live-handoff` は workspace・pane・走行中のエージェント・**両方の label** を保つのに **metadata token を全部落とす**（実測）。#417 が workspace label を人間可読へ rename したため、**再起動をまたぐと rename 済み workspace の所有マーカーがゼロになり、`session/list` が空を返して `doctor` の孤児 pane 検出が盲目になっていた**。`PaneInfo.label` は `WorkspaceInfo.label` とは別フィールドで、書くのは `pane.rename` だけ — **totsuka が一度も呼んでいなかった、#416 が見つけた空白そのもの**。ここに置けば表示用の名前と機械マーカーがフィールドを奪い合わない。`list_sessions` は元からこの経路を読んでいるので**読む側は 1 行も変わらない**。rename は pane label が付いたことを前提条件に加えた（**最後のマーカーを消して rename しない**）
* **Update**: ADR-0039 の `description` と不採用案の節が **「`pane.rename` を採らない」と言ったまま**になっていたので訂正した。退けていたのは「pane label を人間に見せる」ことで、「pane label を使う」ことではない。**「冗長な 2 経路」は独立に壊れるときだけ冗長である** — #417 は label と token を 2 経路のつもりで用意したが、rename が片方を潰し handoff がもう片方を潰す順序が実在した [agent-ide-herdr プラグイン](/components/agent-ide-herdr.md)
