* **Update**: プラグインの**死活監視を全 kind へ広げ、予算付きの自動再起動**を入れた（[#495](https://github.com/tomoya-k31/totsuka/issues/495)、[ADR-0051](/decisions/adr-0051-plugin-supervision.md)、[orchestrator-core](/components/orchestrator-core.md)）。直した非対称はこれ: 死活検知は `agent_ide` にしか配線されておらず、しかも**通知ストリームの終端**に紐づいていたため、`task_source` が死ぬと**イベントが一切発生せず** `totsuka run --watch` は起動したまま永久にタスクを受け付けなくなっていた（痕跡は WARN 1 行のみ）。**当時は妥当だった** — 巻き戻すべき在席タスクを持つのは agent だけで、`tasks/fetch` のポーリング時代は次のポーリングが自然な再試行だった。**0.2.0 で task_source が push 専用になった時点**（[ADR-0008](/decisions/adr-0008-task-submit-push-ingestion.md)）でその前提が消えていたのに、配線だけが取り残されていた。設計の要点は 4 つ。**(1) 検知を子プロセスの終了そのものに紐づけた** — 通知ストリームは購読した agent にしか存在せず、`state_stream` を宣言しない agent には最初から無い。**(2) `Liveness`（`Live`/`Crashed`/`ShutDown`）で「クラッシュ」と「意図した停止」を区別する** — トランスポートから見ると両者は同じ（子が消え stdout が閉じる）ので、区別しないと**正常終了のたびに全プラグインを再起動する**。`shutdown()` は子が消えうる操作の**前**に `ShutDown` を書き、後から来る EOF は先着優先で弾かれる。`Plugin` の drop で `Crashed` が立つのは `kill_on_drop` が実際に子を殺すためで正しく、害が無いのは再起動が drop するのが**古いインスタンスだけ**（その watcher は既に発火済み）だから。**(3) 再起動の判断はコア側（`run::supervise`）に置いた** — 答えが kind ごとに違うため。**agent は「在席タスクを畳む → 再起動」の順序が load-bearing** で、逆にすると新プロセスのセッション ID が死んだプロセスのタスクに紐付いて復旧不能になる。**(4) 予算を使い切ったら黙らない** — 指数バックオフで最大 5 回・5 分の**スライディング窓**（通算回数ではない。週 1 で落ちるプラグインはこの予算が止めるべき障害ではなく、`--watch` は何週間も上がり続ける）。尽きたら `NotifierEvent::Escalated` を配送し、**`task_id` も `workflow` も `None` にする** — プラグインの死はどのタスクのものでもなく、たまたま走っていたタスクに紐づけると誤帰属になる。再起動回数は `RunSummary.plugin_restarts` にも出す。`[plugins.{name}].restart = false` で個別に無効化でき、**無効化しても検知は残る**（止まるのは再起動だけ）。**プロトコル変更なし。`doctor` にもチェックを足していない** — 既存の `plugin:{name}` が起動と `config/validate` を既に見ており、`doctor` は別プロセスなので稼働中の orchestrator のプラグイン集合を観測できない。ここで足すのは [#496](https://github.com/tomoya-k31/totsuka/issues/496) が扱う「重複した宣言」を自分で作ることになる。`plugin_host` の doc comment「v1 does not auto-restart」は同一 PR で撤回した。テストは 7 本（`Liveness` 3 + supervision 4）で、`mock_plugin` に**ファイル backed カウンタ**の `suicide` モードを足して駆動する — 起動のたびに別プロセスなので、プロセス内カウンタでは「いつか復帰する」を書けない。**予算を使い切ったときにエスカレーションが飛ぶことを独立した testcase にした**。検知配線を外すと 4 本中 3 本が落ちることを確認済み。
