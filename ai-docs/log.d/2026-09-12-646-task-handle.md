* **Update**: [ADR-0071](/decisions/adr-0071-task-identifier-naming.md) に **D-7（`Task.handle`）** を追加した（#646）。識別子は `<task 番号>-<hash8>` で「どのタスクか」には答えるが「**何の**タスクか」には答えず、herdr の 32 文字にはまだ 20 文字ほど余っていた。protocol 0.7.2 で `Task.handle` を足し、ソースが人間向けの短い名前を書く（GitHub は `{repo}-{issue 番号}`、Slack と Discord はチャンネル**名**、Notion は**無し**）。予算が足りないとき切られるのは handle だけで、番号（台帳へ戻る手段）とダイジェスト（一意性）は落とさない。**Slack は当初案の `{channel}-{ts 秒}` を採らなかった** — ts は予算で数字の途中で切られるうえ、それが区別するもの（同一チャンネルの 2 スレッド）は task 番号が既に区別している。Notion の `None` は欠落ではなく正しい答えで、title から作ると改名可能な文字列が識別子に入る。
