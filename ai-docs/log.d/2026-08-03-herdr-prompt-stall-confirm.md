* **Update**: [ADR-0032](/decisions/adr-0032-herdr-protocol-17.md) D-7 に 3 段目を追加し、[agent-ide-herdr](/components/agent-ide-herdr.md) に実装（[#380](https://github.com/tomoya-k31/totsuka/issues/380)）。`agent.prompt` の `agent_prompt_stalled` は herdr の 5 秒下限（`wait.timeout_ms` とは別物で、`herdr --default-config` にも該当キーが無く設定不可）に Claude Code が間に合わないときに返り、実機 7 タスク中 3 回発生した。**このときプロンプトは既に投入済み**なので、`agent_pane_busy` / `agent_not_ready` と違い再送してはならない（タスクの二重投入になる）。`agent.wait` でこちらの窓を使って確認し、到達すれば成功、しなければ元の stall を報告する。`agent.wait` が `agent_not_found` を返したときだけそちらを通し、resume 付き dispatch の `SESSION_UNRESUMABLE` を埋もれさせない。
