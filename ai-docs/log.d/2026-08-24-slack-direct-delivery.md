* **Update**: [task-source-slack](/components/task-source-slack.md) — #548: `result/publish` が `delivery = "direct"`（protocol 0.5.2）を受けると、下書き・承認ボタンを作らず**スレッドへ即時投稿**するようにした（[ADR-0057](/decisions/adr-0057-per-workflow-publish-and-cleanup.md)）。名義は従来どおり本人（user token）で、`<@sender>` の機械的前置も draft 経路と同一 — 変わるのはゲートだけであり、それも Orchestrator が `[[workflows]].publish` から指示した workflow に限る。
* **Update**: **direct の座標消費は投稿成功の後**。`publish_draft` は take → 下書き作成の順で、消費後も `drafts.json` に下書きが残るから API 失敗から復旧できる。direct には残るものが無いので、先に消費すると `chat.postMessage` 失敗の時点で再送手段が消える（プラグイン再起動でも pending は戻らない）。peek（`pending()`）→ 投稿 → 成功後に `take_pending` の順にし、**失敗した投稿の座標が残って再送で成功する**ことを統合テストで固定した（`Canned::Network` → 成功、の 2 段）。
* **Update**: **未知の `delivery` 値は draft 経路**に落ちることを統合テストで固定した（`"hologram"` → エフェメラルが出る）。分岐は raw フィールドの match ではなく `effective_delivery()` を通す — 欠落（0.5.2 以前の Orchestrator）も未知値も承認フローに解決され、プラグインはどちらだったかを知らない。server 側の match は `_` ではなく全バリアント明示で書き、**将来の配送モードが黙って draft に落ちずコンパイルエラーで現れる**ようにした。
* **Update**: レビュー（/code-review、6 件全て妥当）を受けた修正。①**direct 経路が Block Kit `markdown` ブロックを使っていなかった** — approve 経路（#454 / [ADR-0046](/decisions/adr-0046-slack-markdown-block.md)）と同じ内容が direct だけ描画崩れする「同じクラスの穴の片側」。配送モードが変えるのは**ゲートだけ**で見た目ではない — 承認を飛ばせるほど信頼した workflow ほど描画が悪くなる形だった。テストにも `blocks` 検証が無かった（検査が主張より弱い）ので追加。②`publish_direct` を挿入した位置が `publish_draft` の doc コメントを**分断**しており、direct の doc が draft の先頭文を抱えて自己矛盾・draft 側は主語の無い断片だけが残っていた。**手前への挿入は直前の doc を置き去りにする**（#464 で踏んだ形の再演）。③モジュール doc の「Only an approval posts to the thread」が同 PR で偽に。④orchestrator-spec の F-07（en/ja + 生成物 2 面）が「承認を経てのみ」のまま — 生成元 5 本の 1 つなので同一 PR 更新義務の対象だった。
* **Update**: ⑤[ADR-0057](/decisions/adr-0057-per-workflow-publish-and-cleanup.md) の「`cleanup = "manual"` は doctor が孤児として数える」は**コードより強い主張**だった。`check_orphans` の known 集合は `list_tasks()` の worktree を **state 無関係に**全部含むので、タスク行が残る worktree は定義上孤児にならない — 孤児検査は「DB に対応が無い worktree」のためのもので、これは「対応があるが残す判断をした worktree」。**manual の worktree は黙って溜まる**（見えるのは `totsuka status` とディスク使用量だけ）と書き直した。⑥[ADR-0003](/decisions/adr-0003-slack-reply-assistant.md) に ADR-0057 の部分改訂注記を追加（ADR-0021 の先例と同じ相互参照）。
