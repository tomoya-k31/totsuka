* **Creation**: 秘密参照の第 5 形式 **`bw:<item>/<field>`** を追加した（#699、[ADR-0076](/decisions/adr-0076-bitwarden-secret-backend.md)）。公式 Bitwarden CLI（`bw get <field> <item> --nointeraction`）へのシェルアウトで解決する。**`bw://` は採らない** —— `op://` は `op read` が実際に受理する本物の URI だが Bitwarden に URI 表記は存在せず、`//` を付けると存在しない URI の発明になる（ADR-0044 が `cmd://` を蹴ったのと同じ理由）。`<field>` は `bw get <object>` の object 名そのもので**指定の仕方が公式 CLI と一致**し、語彙は検証しない（Bitwarden の更新に totsuka のリリースを待たせない）。**分割は最後の `/`** —— アイテム名は `/` を含みうるが object 名は含まないため、`keychain:` とは規則が逆になる。**`BW_SESSION` 未設定は spawn する前にエラー化する**: `bw` は `op` と違い常駐セッションを持たず、セッションが無いと stdin でマスターパスワードを訊くので、常駐する `totsuka run` が踏むと画面に何も出ないまま止まる。カスタムフィールドは公式 CLI に単一コマンドの取得手段が無いため射程外とし、`cmd:bw get item … | jq …` に委ねる（ADR-0044 の責務分担）[設定リファレンス](/development/config-reference.md) [設定例](/development/config-examples.md)
* **Update**: [orchestrator-core クレート](/components/orchestrator-core.md)に `platform::bitwarden` / `SecretRef::Bitwarden` / 合成ストアの振り分けを追加し、接頭辞の一覧を `ports::secret::parse_scheme` の 1 箇所に集約した（resolver は `is_secret_reference` でそこから導出する。#699 まで独立のリストを持っていた）。[orchestrator-cli](/components/orchestrator-cli.md) には `check_bitwarden` を足し、probe の差分を `BackendProbe` テーブル 1 枚に集約して 2 バックエンドが同じ 4 分岐を同じ精度で報告することをテストで固定した。`bw status` は locked でも exit 0 を返すため、判定は JSON の `status` が `unlocked` であること（パース不能は locked 扱い）
* **Update**: Copilot レビューを受けて `bw:` の穴を 3 つ塞いだ（#701）。**(1) `bw://item/password` がパーサを通っていた** —— `bw:` を剥がすと本体が `//item/password` になり、最後の `/` で割ると item が `//item` になる。ADR-0076 が「Bitwarden に URI 形式は無いので `//` は付けない」と決めた綴りを黙って受理し、`bw get password //item` を実行して「名指しした覚えのない item が無い」というエラーを返す形だった。`op://` からの類推で最も書かれやすい綴りなので、分割前に `/` 始まりを弾く。**(2) `bw` 未導入かつセッション無しのとき、インストール導線ではなく「`bw unlock` しろ」と案内していた** —— `bw` が無いのだから堂々巡りになる。セッション欠如時は `--version`（プロンプトしない）で存在を先に確かめる。**(3) doctor の skip 文面が「プロンプトが出る」と言っていた** —— このバックエンドは spawn 前に弾き `--nointeraction` も渡すので、起きるのは失敗であってプロンプトではない。起きえないハングを探させる文面だった。あわせて `bw status` が `unauthenticated` と `locked` を区別するのに次アクションが `bw unlock` しか出していなかったのを `bw login` 込みにし、`probe_cli` の argv 構築に seam とテストを入れた（決定側は `CliProbe` で覆われていたが、何を実行するかは未検証だった）
