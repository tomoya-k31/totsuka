* **Creation**: [ADR-0054 組み込みプロンプトは英語で書き、成果物の言語は文脈に従わせる](/decisions/adr-0054-prompt-language-policy.md) — プラグインの `defaults.toml` が持つ指示文を英語へ統一するにあたり、Slack の `reply_instructions` に焼き込まれていた「返信案を**日本語で**作成してください」をどう扱うかが問題になった。`in Japanese` と訳すと英語化の目的を自ら潰すので、**言語を名指しするのをやめて規則に置き換えた** —— `Write the reply in the same language as the thread.`。追加の入力源は要らない: 利用者の言語は既にタスク本文（Slack スレッド・Issue 本文）としてエージェントに渡っている。`LANG` / `LC_ALL` から導出する案は却下（macOS の Terminal は `LANG` を設定しないことが多く、エージェントは herdr のペインで動くので totsuka の環境とは別物で、POSIX locale は「文章を書く言語」ではなく、外れても静かに外れる）。`output_language` キー新設は見送り（上書きの口は `[prompts]` / `reply_style` / `initial_prompt` の 3 つが既にある）。
* **Update**: `defaults.toml` の指示文を英語化した —— [task-source-slack](/components/task-source-slack.md)（`reply_instructions` / `implement_instructions` / `triage_instructions` / `reply_style_suffix`）、[task-source-github](/components/task-source-github.md) と [task-source-notion](/components/task-source-notion.md)（`triage_instructions` / `design_instructions` / `implement_instructions`）、[agent-ide-orca](/components/agent-ide-orca.md)（`plan_prefix`）。`crates/orchestrator-core/src/prompts/defaults.toml` は 385 行が最初から英語だったので、これで揃った。
* **Update**: **人間が読む文字列は日本語のまま残した。** slack の `body_template` / `body_thread_header` / `body_thread_line` / `body_thread_unavailable`（タスク本文のラベル。ペインで読むのは人間）と、Rust ソースの UI 文言（Slack の承認 UI・macOS 通知のタイトル）。`defaults.toml` の中身は 1 種類ではなく「エージェントへの指示 / 成果物の言語指定 / 人間も読むラベル」の 3 つが混ざっており、英語化の対象は 1 つ目だけである。
* **Update**: **#318 / #317 のバイト同一テストが 3 キー分だけ弱くなった。** `reply_instructions` / `reply_style_suffix` / orca の `plan_prefix` は意図的に書き換えたので、期待値を `defaults.toml` から貼り直した —— これらのテストのコメントは「pre-#318 のソースから転記した、`defaults.toml` から再導出していない（すると vacuous になる）」と明言していたので、**その注意書き自体を直した**。貼り直した分は意図しない編集しか検出しない。`reply_instructions` を意味で守るのは `the_reply_instructions_ask_only_for_a_reply`（#527 の門番）のほうで、こちらは #527 の形を差し戻すと落ちることを実測で確認した。
