* **Update**: [ADR-0071](/decisions/adr-0071-task-identifier-naming.md) D-1 に「**core を一致させるには `case` を揃える必要がある**」を追記した（#646 のレビュー指摘）。初版の core は数字と小文字 hex だけだったので `Case::Lower` と `Case::Preserve` の差が出力に現れず、herdr だけ `Lower`・worktree と orca は `Preserve` で問題無かった。D-7 の `handle` は**英字を持ち込む最初の部分**で、`Web-App-42` のような GitHub の handle はそこで割れる（herdr `t-3-web-app-42-…` / 葉 `3-Web-App-42-…`）。3 つとも `Case::Lower` に揃え、クロスポリシーの回帰テストで固定した。**長さだけは揃わない**（herdr の 32 文字は他に無く、全員を最も狭い制約に合わせると将来ツールが増えるたび全員の名前が縮む）ので、**あらゆる場合に byte 一致するのは `<hash8>`** であることを明記した。
* **Update**: [orchestrator-core](/components/orchestrator-core.md) と [agent-ide-orca](/components/agent-ide-orca.md) を handle 込みに更新した。あわせて `{task_number}-{handle}-{hash}` と手で書いたものが `{worktree_name}` と一致するのは **handle があるときだけ**（無いソースでは空文字が入りテンプレート側の区切りが残る）ことを、コード側のコメントと合わせて明記している。
