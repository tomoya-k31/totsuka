* **Update**: [click-to-focus セットアップ](/operations/click-to-focus-setup.md) と [notifier-macos](/components/notifier-macos.md) が、notifier の設定ファイル名を **`plugins/notifier-macos.toml` と誤記していた**のを直した（正しくは `plugins/macos.toml`）。名前は**プラグイン名**であってクレート名ではない —— crate は `notifier-macos` だが `plugin.toml` の `name` は `macos` で、設定パスは `{plugin_config_dir}/{name}.toml` として導出される（`plugins/spec.rs`）。**この誤りは黙って効く**: `notifier-macos.toml` を置いても読まれず、エラーも警告も出ず、通知は届き続けるがクリックは osascript のまま（＝スクリプトエディタが開く）で、Playbook の目的そのものが達成されない。実際に踏んで発覚した。Playbook 側には「なぜ間違えやすいか」を 1 行残した。`plugins/notifier-macos/src/config.rs` の doc コメントも同じ誤記だったので直した。ファイル名が実際に読まれていることは `deny_unknown_fields` で実測して確認した（不明キーを足すと `initialize` が `-32003` で落ち、外すと通る）。
