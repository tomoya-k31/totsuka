* **Creation**: [ADR-0089](/decisions/adr-0089-orca-env-fifo.md) — orca プラグインは `tool_launch.env` を `exec env K=V …` として端末に打ち込むのをやめ、`0600` の FIFO で渡す（#744）。フックのトークンと指示文の全文が画面とスクロールバックに平文で残っていたため。読み込みは `. "$1"` ではなく `cat` + `eval`（macOS の `/bin/sh` = bash 3.2 の `.` は FIFO から何も読まない）。読み手が 60 秒現れなければ、FIFO を消してディスパッチを失敗させる
* **Update**: [agent-ide-orca](/components/agent-ide-orca.md) に `handoff` モジュールを足し、`launch` とディスパッチの写像、テストの説明を FIFO 方式に合わせた。起動方式が変わったので `verified` を外した
